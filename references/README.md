# References

This folder records the source of every screening tool used in SokhaPheap.

| Folder | Contents |
|---|---|
| `sources/` | Archived source documents (papers, guidelines, official forms), with their SHA-256 hash in each method card |
| `methods/<module-id>/METHOD_CARD.md` | For each module: source, exact items, scoring and cut-offs quoted from the source, eligibility, red flags, next steps, Khmer version, licence and review status |
| `reviews/` | Clinician and Khmer sign-off records (who and when). A module becomes `clinician_verified` only after a review record exists here. |
